# Curation & QSAR modelling of clinical-stage GPCR ligands

Code and data for the MSc thesis
*"Curation and Cheminformatic Characterisation of a Clinical-Stage GPCR Ligand Dataset for
Machine-Learning-Based Binding-Affinity Prediction"* (University of Verona, 2025–2026).

A fully reproducible, **notebook-driven** pipeline that (1) fetches clinical-stage GPCR ligand
bioactivity from ChEMBL, (2) curates it into a locked dataset, (3) builds and honestly validates a
5-HT₂A binding-affinity model, and (4) regenerates **every figure** in the thesis.

## Dataset at a glance
- **3,011** compound–target records · **719** unique molecules · **47** targets · **18** receptor families
- Source: **ChEMBL v36 (October 2025)** — human *Kᵢ* binding data, clinical Phase I–IV, < 700 Da
- Headline model: **ECFP4 + Random Forest**, 5-HT₂A — mean held-out R² = **0.355** (95% CI [0.11, 0.60])
  under a repeated Bemis–Murcko **scaffold split**, passing y-randomisation (p ≈ 0.01) and beating a
  nearest-neighbour read-across baseline.

## The pipeline — four notebooks, run in order from the repo root
```
01_fetch_chembl.ipynb        ChEMBL v36 ─► data/raw_filtered.csv  (+ data/fetch_report.csv)
02_curate_descriptors.ipynb  salt/peptide/pKi/dedup + 15 descriptors ─► data/curated_15desc.csv
03_model.ipynb               5-HT2A benchmark + baselines ─► data/results/baseline_comparison.csv
04_figures.ipynb             regenerate ALL 26 figures ─► figures/*.png
```

## Reproduce
```bash
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```
Then run notebooks `01 → 02 → 03 → 04` from the repo root (Jupyter/Colab). The shipped
`data/curated_15desc.csv` is the exact locked dataset, so notebooks 1–2 are optional. CLI equivalents:
`python src/baseline_run.py`, then `python src/make_figures.py && python src/extra_figures.py &&
python src/model_figures.py && python src/mol_grid.py`.

## Reproducibility & the ChEMBL version
ChEMBL is a **versioned, growing** database; all counts here are pinned to **v36 (October 2025)**.
`chembl_webresource_client` always queries the *latest* ChEMBL, so re-running against a newer release
returns a closely similar but **not identical** dataset. A representative live re-fetch after v36 gave
**~2,960 curated records** (5-HT2A set n approx 168) and a headline **R2 approx 0.32** - versus
**3,011 / n=172 / R2=0.355** for v36. Both move only marginally, so the dataset and results are stable
to database version; the small differences are expected ChEMBL curation drift, not a pipeline change.
To reproduce the exact v36 counts you need the v36 archive. `data/fetch_report.csv` (Notebook 1) logs
per-target survival at each filter, so any difference is fully traceable.


## Curation notes
- Labels are the ChEMBL `pchembl_value` (= pKi); multiple measurements per (compound, target) are
  deduplicated by keeping the **highest** pKi. Pooling Ki across heterogeneous assays carries a known
  ~0.5-log noise floor (Kramer et al. 2012; Landrum & Riniker 2024, *JCIM* 64:1560) that bounds R².
- Structures are salt-stripped to their parent; molecules with >= 2 amide-backbone bonds are removed as
  peptides; a > 10 rotatable-bond cut limits conformational flexibility.

## Data availability
All bioactivity data derive from the open [ChEMBL v36](https://www.ebi.ac.uk/chembl/) database. Raw ChEMBL
bulk data are **not** redistributed; `01_fetch_chembl.ipynb` reproduces the dataset from the public source.
